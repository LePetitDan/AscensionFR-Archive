# Pour Claude Code — les demandes d'exécution

Je ne lance jamais de script. Quand il faut exécuter quelque chose, j'écris une
demande ici (modèle : `MODELE_demande.md`) et je préviens Dan.

Le rituel :

1. J'écris `AAAA-MM-JJ_sujet.md` — l'objectif, ce que « terminé » veut dire,
   les fichiers concernés.
2. Dan ouvre Claude Code et lui dit de lire la demande.
3. Claude Code l'exécute, écrit sa réponse en bas du fichier, et le renomme
   en `AAAA-MM-JJ_sujet_FAIT.md`.
4. Je lis la réponse et j'enchaîne.

Un fichier sans `_FAIT` = pas encore exécuté.
